\# KasirKu Mini



Proyek Praktikum Pemrograman Berorientasi Objek (PBO).



Aplikasi kasir sederhana menggunakan bahasa pemrograman Dart.



\## Materi Praktikum

\- Class dan Object

\- Inheritance

\- Encapsulation

\- Polymorphism

\- Abstract Class dan Interface

\- Mixin

\- Transaksi dan Cetak Struk



\## Menjalankan Program

dart run lib/main.dart
